# Activación de usuarios y datos de recuperación

## Enlace de activación vencido
Cuando se da de alta una cuenta nueva, el sistema envía un enlace para activar el usuario. Ese enlace de activación vence 72 horas después de enviarse. Si el enlace expiró, entra al portal de autoservicio, elige «Reenviar activación» y escribe tu correo institucional. Se puede reenviar la activación hasta tres veces; después de eso es necesario abrir un reporte con la mesa de ayuda.

## Formato del nombre de usuario
El nombre de usuario se forma con la inicial del nombre, el primer apellido y, si ya existe, un número consecutivo, por ejemplo «mlopez2». Se escribe en minúsculas y sin acentos. Si el portal rechaza tu nombre de usuario, verifica que no estés escribiendo tu correo completo, mayúsculas o espacios al final. El nombre de usuario no se puede cambiar después de activado.

## Correo de recuperación de una cuenta anterior
Si el correo de recuperación registrado pertenece a una cuenta anterior que ya no usas, no podrás recibir enlaces ni códigos. Para cambiarlo, llena el formulario «Actualizar datos de recuperación» y adjunta una identificación oficial vigente. La mesa de ayuda valida el formulario y actualiza el correo de recuperación en un máximo de dos días hábiles.

## Cuentas para personal externo
El personal externo o temporal recibe una cuenta con vigencia limitada a la fecha de término de su contrato, con un máximo de seis meses. La cuenta la solicita el área contratante, no la persona externa. Al vencer, la cuenta se desactiva y sus archivos de NubeTec se conservan 30 días antes de eliminarse.

## Baja de una cuenta
Cuando una persona deja la organización, su cuenta se desactiva el último día laboral. Los archivos personales se conservan 30 días para que el área responsable los transfiera. Después de ese plazo no es posible recuperarlos.
